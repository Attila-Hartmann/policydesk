# Sample data

Fictional internal policies of *Pannonfield Advisory Kft.*, a made-up Budapest professional-services firm. Every name, amount, address, phone number and email address is invented; `pannonfield.example` uses a domain reserved for documentation. The content is synthetic and contains no confidential or personal data.

The documents are deliberately specific (limits, deadlines, exceptions), so you can check whether an answer came from the right place. Swap in your own Markdown files and run the ingest command again to use different documents.
